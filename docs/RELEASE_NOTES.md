## ORBIT 0.4.3 public.1

腕上 Codex 的首个公开源码版本，MIT 许可。

包含手环 RPK、原生音频/NSH/Link 源码、专用蓝牙、Android shell 字节管道、
Termux 业务桥接、五款数字表盘及完整部署文档和 AGENTS.md。

验证：174 项 Node 测试、4 组 C 测试、23 个恢复/首装 Lua 场景、
五款表盘模型和 RPK 构建。三个原生模块已在独立环境从源码逐字节复现。
Gitleaks 和本机真实设备密钥比对均无命中。

支持基线：M2551B1 / p67cn / 3.101.043。新设备需要自己的厂商认证材料和
按实际上传回执生成的首次安装/恢复入口。附件不包含这些私有材料和部署表盘。

附件包含：新公开签名的 RPK、五款纯显示表盘、三个固定原生模块、手机字节管道及 SHA256。
新签名包不保证覆盖其他签名安装的同包名 App；源码构建者应保留自己的签名。
签名私钥、真实录音、登录、配对数据和固件镜像均不发布。

本版标为 prerelease：公开首装流程尚未在第二只恢复出厂手环验收；
实验性转写、长期后台保活和页面恢复延迟仍有限制。
RPK 构建工具的开发依赖有已知漏洞，详见 docs/VALIDATION.md。
