# 验证范围

## 原设备完成的历史验证

基线为 M2551B1 / 3.101.043，ORBIT RPK 0.4.3、原生 Link v4：

- 真人语音在 App 内录音、回传、转写、核对和手动确认后到达 Codex。
- 三段连接中 App RPC 为 0、App 唤醒为 0，仍完成文件和 Shell 管理。
- 11 项真实 NSH 测试：系统查询、输出、非零退出、250 ms 超时回收及私有文件读写删除。
- 131075 B 非重复二进制双向传输，两方向各中断一次本项目管道，
  保留同一任务编号续传后逐字节与 SHA256 一致。
- 原生短时采集、专用蓝牙回传、手机 Opus 解码成功。
- 固定只读测试对话完成发送、回复和 App 消息回执。
- 五款纯显示日用表盘与统一恢复入口部署；原设备确认时间日期正常。

原始设备日志、聊天、真实音频和诊断目录未公开。这里是去除设备身份后的结果摘要，
不是可以替代原始日志的独立审计证明。

## 公开版

公开版是在独立目录中整理的源码，不会覆盖原设备工作目录：

- 设备地址和厂商认证从本机私有配置读取。
- 原生源码使用本地 ARM GNU 工具链编译，不依赖原研究服务器。
- 新设备首装/恢复按该设备实际传输回执生成，不复用原设备文件 UUID。
- 176 项当前范围的 Node 测试，另有 C、Lua 和配置/打包验证。
- 老版本录音机方案、旧伴侣、私有授权记录和只依赖历史产物的测试不作为本版入口。

具体本次执行结果见 PUBLICATION.json 和 GitHub Actions；失败测试不会被写成通过。
原设备历史 180 项测试中有 6 项针对未发布的旧录音机页面，公开版未包含这组历史测试。
public.1 的 174 项测试基础上，public.2 新增两项厂商通道锁兼容性测试；
另有八项合成反例验证发布检查确实读取暂存区并拒绝私有文件与符号链接。
完整复核范围与修复见 [公开版复核](REVIEW.md)。

## 仍需验证

- 公开首装 helper 在第二只恢复出厂手环上的端到端安装。
- 新签名 RPK、不同安卓构建及不同 Codex 安装的现场兼容性。
- 长期后台存活、Termux 退出后的自动恢复、完整离线场景。
- 页面恢复延迟：历史一次消息验收有约 112 秒恢复耗时；
  后续补了页面存活探测，但未据此宣称即时或完成长期稳定性验收。
- 更大文件、其他固件和通用的设备内离线 NSH 安装器。

新版本公开构建的成功、离线模型成功和在设备上实际运行成功，必须分别报告。

## 构建依赖审计

公开版保留可重现 RPK 的 aiot-toolkit 1.1.4 锁定依赖。
2026-11-03 安装时 npm 报告其开发依赖有 50 项漏洞（7 low / 22 moderate / 9 high / 12 critical）；
它们尚未全部升级修复。使用可信源码在隔离的构建环境中运行工具链，不把开发服务器开放到网络。
本次根目录 ws 运行依赖及 band 的非开发依赖审计均为 0 项。
不能把这两项结果宣传为整个开发工具链没有已知漏洞。
