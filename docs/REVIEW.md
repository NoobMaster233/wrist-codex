# 公开版复核 · 2026-11-03

复核对象为公开 GitHub 仓库、通用二进制附件，以及另一位所有者或 agent 的部署入口。
从 GitHub 全新 clone 到独立 Linux 目录验证，同时在 Termux 运行修复后的测试。

## 查出并修正

1. **Linux 兼容性。** 原厂通道锁依赖名为 python 的命令；只装 python3 的环境会失败，
   并被误报为“通道被占用”。改为当前 Node 可执行文件，并区分锁竞争和辅助进程失败。
   添加两项回归测试，其中一项仅允许 PATH 中存在 flock。
2. **部署前置条件。** SETUP 未明确列出 flock。现已补上 util-linux、doctor 检查和 CI 依赖。
   文档也说明 Linux 离线环境应使用 python3，Termux 使用 python。
3. **发布检查。** 原检查没有完整覆盖强制暂存的 .env 等文件，符号链接判断还依赖工作目录。
   现直接检查 Git 暂存区的文件类型，补充登录 JSON、音频、数据库和小写设备地址。
   八个合成反例验证：清理工作目录不能隐藏暂存内容；暂存的符号链接也不能被普通文件替换掩盖。

这些是检查工具和可移植性问题。此次扫描没有发现公开版本已包含真实秘密。

## 复核没有消除的边界

- 公开首装 helper 仍未在第二只恢复出厂手环上验收；离线模型通过不等于新设备硬件通过。
- 原生代码只适配 M2551B1 / 3.101.043，接入仍需设备自己的认证材料。
- 转写使用实验性的 ChatGPT 会话接口；长期后台存活和页面恢复延迟仍需继续验证。
- aiot-toolkit 1.1.4 的开发依赖仍有已披露漏洞，详见 VALIDATION；此次未宣称全部修复。

本次未操作手环、录音或发送消息，也未重启正在运行的 Codex 服务。
